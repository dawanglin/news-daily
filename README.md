# 每日生活热点简报

面向手机阅读的公开中文简报。每天从公共热榜发现话题，再用中文媒体 RSS 补充事实与专业信息，通过免费规则完成去重、分类、排序和说明。

在线地址：<https://dawanglin.github.io/news-daily/>

## 内容结构

- 今日必看：从不同栏目中选择 8 条
- 今日热议
- 社会与民生
- 钱包与消费
- 吃喝住行
- 健康教育家庭
- 工作与科技
- 文娱与体育
- 世界与中国

每条内容包含标题、简要事实、来源、可信度类型和“为什么值得看”。热榜只作为关注度线索，不等同于事实核实。

## 数据来源

- 热度发现：百度热搜、头条热榜、B站热门
- 报道与专业来源：中国新闻网、BBC 中文、少数派、IT之家、Solidot、量子位

只读取公开页面、公共接口和 RSS，不绕过登录或访问限制。

## 技术特点

- 不使用 AI 大模型，不需要 API 密钥
- 纯 Python 标准库，零第三方依赖
- GitHub Actions 每天下午 17:00（北京时间）更新
- 手机优先，自动适配系统深色模式
- 每日数据和历史网页随仓库存档

## 本地运行

```bash
python fetch_news.py
python build_site.py
```

## 可调整项

编辑 `config.py` 可以修改媒体来源、栏目顺序、抓取数量、每日总量和“为什么值得看”的栏目说明。关键词分类规则位于 `fetch_news.py`。

## 内容边界

- 不完整转载原文，只保留摘要和原始链接
- 不把热榜热度当成事实结论
- 医疗、金融和争议事件应回到原始报道确认
- 某个来源失败不会阻断其他来源和网页部署
