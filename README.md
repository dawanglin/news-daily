# 每日个人情报流

一个面向手机阅读的公开中文信息页。它不追逐泛新闻，而是围绕个人正在做的事情收集材料：AI 模型、网页与小游戏、编程工具、数学物理、数据空间关系，以及四川本地的直接信息。

## 信息怎样排列

主目录按照一件东西从无到有的过程组织：

1. 行业观察
2. 想法与概念
3. 孵化与转化
4. 工具与硬件
5. 方法与执行
6. 测试与成果
7. 维护与复盘

主题只是第二层标签。页面不设置“必看”，每条信息地位平等，使用者自己逐条判断和吸收。

## 选择规则

- 政治外交、战争、泛国际冲突和纯娱乐体育默认排除。
- 百度、头条和 B 站只承担发现作用，只有命中个人兴趣时才可能出现。
- 优先保留两类内容：足够专业，能够看到方法和测试条件；或者足够科普，能够把概念讲明白。
- 每条内容给出“可以怎么用”，强调下一步动作，不使用通用套话。
- 每天宁可少于 18 条，也不拿无关内容凑数。

## 来源

- AI 与开发：量子位、机器之心、InfoQ 中文、开源中国、IT之家、Solidot
- 科学与科普：科学网数理科学、科学网科普
- 前端与实践：前端技术精选、阮一峰的网络日志、少数派
- 兴趣发现：百度热搜、头条热榜、B站热门（严格过滤）

部分聚合源用于发现原文，页面会保留实际来源和原始链接。

## 自动更新

GitHub Actions 每天北京时间 17:00 自动运行：

1. 抓取候选内容
2. 按个人兴趣过滤
3. 按项目阶段归纳、去重和限额
4. 生成手机页面和历史目录
5. 发布到 GitHub Pages

全流程使用 Python 标准库和透明规则，不使用 AI 大模型，也不需要付费接口。

## 本地运行

```bash
python fetch_news.py
python build_site.py
```

生成结果位于 `site/`。
