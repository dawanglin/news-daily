# 每日情报简报

一个桌面端优先的公开中文信息页（标题「每日情报简报」）。它不追逐泛新闻，而是围绕个人正在做的事情收集材料：云服务器、AI 模型、提示词、Agent、Skill 与插件、网页与小游戏、编程工具、数学物理和数据空间关系；同时长期跟踪一条技术情报主线，由四个专题构成：线下数字化与空间感知、空间数据库与实体关系、MCP 与地理空间工具接口、Agent 编排与自主工程。

## 页面布局

页面分左右两栏，适合在电脑浏览器上连续阅读：

- **新闻情报（主栏）**：按相关度排列的信息流，每条保留轻量标签（主题、内容性质、来源和时间），由使用者自己逐条判断。
- **商业建设观察（侧栏）**：人工整理的商业线索，重点看高德地图及相关的 MCP、Agent、地图 API、位置服务、POI、本地生活与商业应用案例，帮助判断哪些能力可能用于商业项目、能不能试、怎样试。

顶部导航为「新闻情报」「商业建设观察」「生活优惠」三个文字入口；「生活优惠」低调链接到独立优惠网页，不做方框或按钮。

## 选择规则

- 政治外交、战争、泛国际冲突和纯娱乐体育默认排除。
- 百度、头条和 B 站只承担发现作用，只有命中个人兴趣时才可能出现。
- 优先保留两类内容：足够专业，能够看到方法和测试条件；或者足够科普，能够把概念讲明白。
- 同时吸收专业报道、专家观点、教程、真实体验和用户评价，但明确区分专业来源与讨论线索。
- 每条内容给出“落地入口”，强调下一步动作，不使用通用套话。
- 每天目标 20–30 条，目前上限为 26 条；没有足够合格内容时不拿无关信息凑数。

## 四大技术情报专题

不局限于某家地图厂商，也不以消费端应用为主要监测对象；四个专题是同一条技术链的不同环节，持续寻找新技术、开源项目、论文、工具更新和行业突破。

- **T01 线下数字化与空间感知**：现实世界如何变成可计算的数据。跟踪 OCR、视觉语言模型、图像实体识别、视频抽帧、街景理解、空间定位、三维重建、变化检测。
- **T02 空间数据库与实体关系**：数字实体如何建立关系。跟踪 GIS、PostGIS、空间索引、POI 实体对齐、知识图谱、名称地址匹配、主数据管理、增量更新、时空数据库。
- **T03 MCP 与地理空间工具接口**：空间能力如何标准化对外开放。跟踪 MCP Server、地图 API、地理编码、空间查询工具封装、Agent Skills、跨模型接口兼容。
- **T04 Agent 编排与自主工程**：自然语言任务如何自主执行、验证和反馈。跟踪多 Agent 编排、任务调度、外部记忆、文件变化感知、自动测试、执行沙箱、工作流恢复、工具调用可靠性。

优先保留有源码、论文、官方文档或实际测试数据的内容；普通营销新闻与技术主线无关的应用宣传降低优先级。当前检索基于现有中文 RSS 与热榜来源完成分类标注；GitHub、arXiv 等英文技术源的直连采集为后续扩展项。

## 来源

- AI 与开发：量子位、机器之心、InfoQ 中文、开源中国、IT之家、Solidot
- 科学与科普：科学网数理科学、科学网科普
- 前端与实践：前端技术精选、阮一峰的网络日志、少数派、小众软件

- 兴趣发现：百度热搜、头条热榜、B站热门（严格过滤）

部分聚合源用于发现原文，页面会保留实际来源和原始链接。

## 自动更新

GitHub Actions 每天多次巡检；北京时间 17:00 前只检查不生成，17:00 后第一次成功运行会创建当天快照。当天文件一旦存在，后续巡检不会重抓或覆盖：

1. 抓取候选内容
2. 按个人兴趣过滤
3. 判断主题和内容性质，去重并按来源、主题限额
4. 生成桌面双栏页面和历史目录
5. 发布到 GitHub Pages

全流程使用 Python 标准库和透明规则，不使用 AI 大模型，也不需要付费接口。

## 商业建设观察数据

侧栏内容来自 `data/business_YYYY-MM-DD.json`（人工整理的 curated 数据），`build_site.py` 读取最新的一份渲染。每条包含：发生了什么（标题+来源+时间）、对应业务场景、小规模验证动作、使用条件与成本、限制与风险，并标注「已查证 / 待核实」。只收录能追溯到原始来源的线索，宁缺毋滥；当天没有合格内容时侧栏显示「今日暂无商业观察」。

## 国内访问镜像

仓库已包含 `edgeone.json`，可直接导入腾讯 EdgeOne Makers，发布目录为 `site/`。EdgeOne 可连接 GitHub 或 Gitee；每次仓库更新后自动重新部署，适合作为手机端国内访问地址。GitHub Pages 地址继续保留为备用。

## 本地运行

```bash
python fetch_news.py
python build_site.py
```

生成结果位于 `site/`。
