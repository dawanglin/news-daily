# 每日个人情报流

一个面向手机阅读的公开中文信息页。它不追逐泛新闻，而是围绕个人正在做的事情收集材料：云服务器、AI 模型、提示词、Agent、Skill 与插件、网页与小游戏、编程工具、数学物理和数据空间关系。

## 信息怎样排列

首页是一条按相关度排列的连续信息流，不要求读者先选择栏目。每条内容只保留轻量标签：主题、内容性质、来源和时间；页面不设置“必看”，由使用者自己逐条判断和吸收。

## 选择规则

- 政治外交、战争、泛国际冲突和纯娱乐体育默认排除。
- 百度、头条和 B 站只承担发现作用，只有命中个人兴趣时才可能出现。
- 优先保留两类内容：足够专业，能够看到方法和测试条件；或者足够科普，能够把概念讲明白。
- 同时吸收专业报道、专家观点、教程、真实体验和用户评价，但明确区分专业来源与讨论线索。
- 每条内容给出“落地入口”，强调下一步动作，不使用通用套话。
- 每天目标 20–30 条，目前上限为 26 条；没有足够合格内容时不拿无关信息凑数。

## 来源

- AI 与开发：量子位、机器之心、InfoQ 中文、开源中国、IT之家、Solidot
- 科学与科普：科学网数理科学、科学网科普
- 前端与实践：前端技术精选、阮一峰的网络日志、少数派、小众软件
- 用户体验与作品：V2EX 技术、V2EX 分享创造（作为线索，不等同于事实核实）
- 兴趣发现：百度热搜、头条热榜、B站热门（严格过滤）

部分聚合源用于发现原文，页面会保留实际来源和原始链接。

## 自动更新

GitHub Actions 每天多次巡检；北京时间 17:00 前只检查不生成，17:00 后第一次成功运行会创建当天快照。当天文件一旦存在，后续巡检不会重抓或覆盖：

1. 抓取候选内容
2. 按个人兴趣过滤
3. 判断主题和内容性质，去重并按来源、主题限额
4. 生成手机页面和历史目录
5. 发布到 GitHub Pages

全流程使用 Python 标准库和透明规则，不使用 AI 大模型，也不需要付费接口。

## 本地运行

```bash
python fetch_news.py
python build_site.py
```

生成结果位于 `site/`。
